# Minimal YouTube 1.5.1

Расширение для Chrome / Chromium / Edge: спокойная главная с поиском, центрированные страницы каналов и видео, без рекомендаций и Shorts.

## Что изменилось

- Главная содержит только логотип, строку поиска и переключатель светлой/тёмной темы под ней. Выбор темы главной сохраняется в расширении и не меняет настройку темы YouTube. Главная отрисовывается отдельным слоем вне нативного body: его фильтры, преобразования и высота больше не создают полосы фона. При выходе с главной или отключении расширения нативная страница восстанавливается. Фон однотонный; отправка поиска — кнопкой с лупой без текста. Поиск адаптивный, с очисткой и управлением с клавиатуры. Enter отправляет запрос, `/` переводит фокус в поиск, Escape очищает поле. Кириллица, `&`, `+` и `#` передаются корректно. Пустой запрос не отправляется.
- Каналы: в шапке остаются логотип и поиск. Обложка занимает всю ширину экрана; профиль и контент остаются центрированными. Панель вкладок и превью видеокарточек скруглены, превью увеличены: на широком экране три видео в ряд, промежутки увеличены. Прокрутка над пустыми боковыми полями работает на каналах, в поиске, при просмотре и на других страницах, в том числе при вложенном контейнере прокрутки YouTube. Область видеоплеера и самостоятельная прокрутка вложенных панелей не перехватываются.
- Просмотр: в шапке остаются только логотип и поиск, описание и информация под видео ограничены колонкой до 900 px. Лайки/дизлайки скрыты; на их месте — кнопка «Комментарии». По умолчанию комментарии полностью свёрнуты; кнопка раскрывает и закрывает родной раздел YouTube, сохраняя ответы и введённый текст. При переходе к другому видео раздел снова сворачивается. Плейлисты, чат, театральный и полноэкранный режимы сохранены. Рекомендации скрыты.
- Результаты поиска: компактные карточки в три колонки, на планшетах — в две, на телефонах — в одну. Сетка учитывает видео со ссылкой на плейлист, дополнительными обёртками и аватаром перед основной ссылкой. У видео остаются превью, заголовок и канал; статистика, описания, бейджи и дополнительные блоки скрыты. В шапке — только логотип и поиск.
- Shorts: скрыты полки, карточки, пункты навигации и вкладки каналов, включая элементы, подгружаемые без перезагрузки. Прямые переходы на `/shorts` и `/shorts/…` ведут на главную; вкладка Shorts канала — на его вкладку «Видео».
- Общая шапка: логотип YouTube и обновлённая поисковая строка центрируются вместе на всех страницах.
- Устранена задержка применения оформления: расширение запускается в начале загрузки, отслеживает начало SPA-переходов и сохраняет оформление при обновлении корневых классов YouTube. При выключенном расширении нативная страница восстанавливается.
- Переключатель расширения применяется к уже открытым вкладкам без перезагрузки. Отключение снимает стили и возвращает скрытые элементы. Главная больше не уничтожает DOM YouTube.
- Popup с русским и английским интерфейсом, доступным переключателем и сообщениями об ошибках сохранения.

## Установка

Готовое расширение: [articafts/minimal-youtube-1.5.1.zip](articafts/minimal-youtube-1.5.1.zip).

Требуется Chrome / Chromium 105+ или совместимый Edge с разрешённой установкой распакованных расширений.

1. Распакуйте `minimal-youtube-1.5.1.zip` в отдельную постоянную папку. Либо используйте корень этого репозитория, где находится `manifest.json`.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`), включите режим разработчика.
3. Отключите прежнюю копию Minimal YouTube, чтобы её стили не конфликтовали с новой.
4. Нажмите «Загрузить распакованное расширение» и выберите папку с `manifest.json`.
5. Обновите уже открытые вкладки YouTube один раз после установки/обновления кода. После этого переключатель работает сразу.

Если браузер управляется организацией и запрещает установку расширений, потребуется разрешение администратора. Расширение использует только разрешение `storage`, не обращается к внешним API и не изменяет YouTube Music. Установка из ZIP не обновляется автоматически через Chrome Web Store.

## Разработка и проверка

Исходники находятся в `src/`, зависимости и сборка JavaScript не нужны. Исходный архив `imnffafnaoooaedkhappfhomnnpigogk.zip` оставлен без изменений для сравнения.

```sh
cd /workspace/yt-min
node --check src/content/content.js
node --check src/popup/popup.js
python tests/smoke.py
python scripts/package.py
```

Для браузерных тестов нужны Python, пакет `playwright` и `/usr/bin/chromium`; в подготовленной cloud-среде они уже установлены. Если системный Chromium расположен иначе, измените путь запуска в тесте. В cloud-среде запуск Chromium может требовать расширенного режима выполнения команды из-за ограничений сокетов.

Тесты проверяют поиск, SPA-переходы, включение/отключение, скрытие динамических Shorts, повторное использование карточек, центрирование, переключатель темы, раскрытие комментариев, сетку результатов поиска, ранний запуск до появления DOM страницы, переходы без задержки оформления, общую шапку и popup на локальных DOM-макетах с имитацией `chrome.storage`. Они не устанавливают расширение и не проверяют актуальный DOM настоящего YouTube. Управляемый Chromium в cloud-среде запрещает распакованные расширения, поэтому полноценную интеграционную проверку нужно выполнить в браузере, допускающем установку.

После установки проверьте главную, канал (главная/видео/плейлисты), поиск, обычное видео, плейлист, прямую ссылку на Shorts, переходы назад/вперёд и переключатель расширения. Убедитесь, что комментарии открываются и закрываются новой кнопкой, а на другом видео снова сворачиваются; выберите тему на главной и обновите страницу. Проверьте светлую и тёмную темы, обычный, театральный и полноэкранный режимы просмотра. YouTube меняет разметку и проводит A/B-тесты: отдельные варианты интерфейса могут потребовать обновления селекторов.

Команда упаковки создаёт воспроизводимый ZIP в `articafts/` с `manifest.json` в корне, без метаданных Web Store, тестов и инструментов разработки. Готовый архив сохранён в репозитории.
