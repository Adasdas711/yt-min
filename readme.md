# Minimal YouTube 1.3.0

Расширение для Chrome / Chromium / Edge: спокойная главная с поиском, центрированные страницы каналов и видео, без рекомендаций и Shorts.

## Что изменилось

- Новая строка поиска: адаптивная ширина, очистка, фокус с клавиатуры, светлая и тёмная темы YouTube. Enter отправляет запрос, `/` переводит фокус в поиск, Escape очищает поле. Кириллица, `&`, `+` и `#` передаются корректно. Пустой запрос не отправляется.
- Каналы: убраны глобальные ограничения ширины, шапка, вкладки и контент располагаются в общей центрированной колонке.
- Просмотр: больше пространства для видео, аккуратные отступы и скругления. Сохранены комментарии, действия, плейлисты, чат, театральный и полноэкранный режимы. Рекомендации скрыты.
- Shorts: скрыты полки, карточки, пункты навигации и вкладки каналов, включая элементы, подгружаемые без перезагрузки. Прямые переходы на `/shorts` и `/shorts/…` ведут на главную; вкладка Shorts канала — на его вкладку «Видео».
- Переключатель расширения применяется к уже открытым вкладкам без перезагрузки. Отключение снимает стили и возвращает скрытые элементы. Главная больше не уничтожает DOM YouTube.
- Popup с русским и английским интерфейсом, доступным переключателем и сообщениями об ошибках сохранения.

## Установка

Требуется Chrome / Chromium 105+ или совместимый Edge с разрешённой установкой распакованных расширений.

1. Распакуйте `minimal-youtube-1.3.0.zip` в отдельную постоянную папку. Либо используйте корень этого репозитория, где находится `manifest.json`.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`), включите режим разработчика.
3. Отключите прежнюю копию Minimal YouTube, чтобы её стили не конфликтовали с новой.
4. Нажмите «Загрузить распакованное расширение» и выберите папку с `manifest.json`.
5. Обновите уже открытые вкладки YouTube один раз после установки/обновления кода. После этого переключатель работает сразу.

Если браузер управляется организацией и запрещает установку расширений, потребуется разрешение администратора. Расширение использует только разрешение `storage`, не обращается к внешним API и не изменяет YouTube Music. Установка из ZIP не обновляется автоматически через Chrome Web Store.

## Разработка и проверка

Исходники находятся в `src/`, зависимости и сборка JavaScript не нужны. Исходный архив `imnffafnaoooaedkhappfhomnnpigogk.zip` оставлен без изменений для сравнения.

```sh
cd /workspace/yt-min
node --check src/content/content.js
node --check src/popup/popup.js
python tests/smoke.py
python scripts/package.py
```

Для браузерных тестов нужны Python, пакет `playwright` и `/usr/bin/chromium`; в подготовленной cloud-среде они уже установлены. Если системный Chromium расположен иначе, измените путь запуска в тесте. В cloud-среде запуск Chromium может требовать расширенного режима выполнения команды из-за ограничений сокетов.

Тесты проверяют поиск, SPA-переходы, включение/отключение, скрытие динамических Shorts, повторное использование карточек, центрирование и popup на локальных DOM-макетах с имитацией `chrome.storage`. Они не устанавливают расширение и не проверяют актуальный DOM настоящего YouTube. Управляемый Chromium в cloud-среде запрещает распакованные расширения, поэтому полноценную интеграционную проверку нужно выполнить в браузере, допускающем установку.

После установки проверьте главную, канал (главная/видео/плейлисты), поиск, обычное видео, плейлист, прямую ссылку на Shorts, переходы назад/вперёд и переключатель расширения. Проверьте светлую и тёмную темы, обычный, театральный и полноэкранный режимы просмотра. YouTube меняет разметку и проводит A/B-тесты: отдельные варианты интерфейса могут потребовать обновления селекторов.

Команда упаковки создаёт воспроизводимый ZIP в `dist/` с `manifest.json` в корне, без метаданных Web Store, тестов и инструментов разработки.
